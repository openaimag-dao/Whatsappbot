# WhatsApp-бот для продаж

Бот на Node.js для официального **WhatsApp Cloud API** (Meta). Умеет:

- 🛍 **Каталог** — категории и товары интерактивными списками WhatsApp
- 🛒 **Корзина** — добавление, просмотр, очистка, подсчёт суммы
- 📝 **Оформление заказа** — имя → адрес → подтверждение, номер заказа клиенту
- 🔔 **Уведомления менеджеру** — новый заказ и запросы «позвать менеджера» приходят на ваш номер в WhatsApp
- 👤 **Режим менеджера** — бот замолкает, пока менеджер переписывается с клиентом (клиент пишет «меню», чтобы вернуться)
- 🤖 **AI-консультант** (необязательно) — отвечает на свободные вопросы о товарах по вашему каталогу через Claude

## Быстрый старт

```bash
npm install
cp .env.example .env   # заполните переменные
npm start
```

Требуется Node.js 22+.

## Подключение к WhatsApp

1. Создайте приложение на [developers.facebook.com](https://developers.facebook.com/) → тип **Business** → добавьте продукт **WhatsApp**.
2. В **WhatsApp → API Setup** возьмите **Phone number ID** → `WHATSAPP_PHONE_NUMBER_ID` и токен → `WHATSAPP_TOKEN`
   (для продакшена создайте постоянный токен System User в Business Manager).
3. В **App settings → Basic** скопируйте **App Secret** → `WHATSAPP_APP_SECRET`.
4. Разверните бота на сервере с HTTPS (Railway, Render, VPS + nginx; для локальной проверки — `ngrok http 3000`).
5. В **WhatsApp → Configuration → Webhook** укажите:
   - Callback URL: `https://ваш-домен/webhook`
   - Verify token: значение `WHATSAPP_VERIFY_TOKEN`
   - Подпишитесь на поле **messages**.
6. Напишите боту «привет».

## Настройка товаров

Отредактируйте `data/catalog.json`:

```json
{
  "categories": [{ "id": "phones", "title": "Смартфоны" }],
  "products": [
    { "id": "p1", "category": "phones", "title": "Смартфон Nova X", "price": 24990, "description": "128 ГБ, NFC" }
  ]
}
```

Ограничения WhatsApp: в списке — до 10 строк (то есть до 10 категорий и до 10 товаров в категории),
название в списке — до 24 символов, описание — до 72 (длиннее обрежется).

## AI-консультант

Укажите `ANTHROPIC_API_KEY` (ключ с [console.anthropic.com](https://console.anthropic.com/)). Тогда на любой
свободный текст бот ответит как консультант, опираясь только на ваш каталог, и подскажет, как оформить заказ.
Модель задаётся в `ANTHROPIC_MODEL` (по умолчанию `claude-opus-5-5`). Если модель откажется отвечать,
запрос автоматически повторяется на резервной модели (server-side fallback). Без ключа бот работает только по кнопкам.

## Заказы

Заказы и сессии клиентов хранятся в `data/db.json`. Посмотреть список заказов:

```
GET https://ваш-домен/orders?token=<WHATSAPP_VERIFY_TOKEN>
```

Для большой нагрузки замените `src/store.js` на Redis/PostgreSQL — интерфейс простой.

## Структура

| Файл | Назначение |
|---|---|
| `src/server.js` | HTTP-сервер, вебхук, проверка подписи, очередь сообщений |
| `src/bot.js` | Логика диалога: меню, каталог, корзина, оформление |
| `src/whatsapp.js` | Отправка текста, кнопок и списков через Cloud API |
| `src/ai.js` | AI-консультант на Claude |
| `src/store.js` | Хранилище сессий и заказов |
| `data/catalog.json` | Ваши товары |

## Важно

- Бот может первым писать клиенту только через одобренные **шаблоны сообщений**; свободные ответы — в течение
  24 часов после последнего сообщения клиента. Уведомления менеджеру тоже подчиняются этому правилу:
  менеджеру нужно хотя бы раз в сутки написать боту, иначе уведомления не дойдут.
- На тестовом номере Meta сообщения доходят только до номеров, добавленных в список получателей.
