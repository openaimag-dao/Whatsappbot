# WhatsApp-бот AIMAG ELECTRIC

Бот для продаж электротехники с сайта [aimag.kz](https://www.aimag.kz) в WhatsApp через официальный **WhatsApp Cloud API** (Meta).

- 📦 **Каталог aimag.kz** — 1 291 позиция в 18 разделах, листание по 9 + «Ещё ▶»
- 🔎 **Поиск** — клиент просто пишет «ВВГнг 3х2,5», «СИП-4 4х50», «автомат 25А» или артикул; понимает `×/х/x/*` и `2,5/2.5`
- 🧾 **Карточка товара** — артикул, производитель, параметры, цена без НДС за м/шт/кг, наличие, ссылка на сайт
- 📝 **Заявка на КП** — позиции с количеством (метры, штуки) → имя/компания → город или самовывоз → комментарий → номер заявки
- 🔔 **Уведомления менеджеру** — заявка (с артикулами) и запросы «позвать менеджера» приходят на номер менеджера в WhatsApp
- 👤 **Режим менеджера** — бот молчит, пока менеджер переписывается с клиентом («меню» — вернуться к боту)
- 🤖 **AI-консультант** (необязательно) — отвечает на вопросы о подборе, доставке, оплате, гарантии на основе
  `data/shop-info.md` и найденных под вопрос товаров; под ответом показывает список товаров для заказа

## Быстрый старт

```bash
npm install
cp .env.example .env   # заполните переменные
npm start
```

Требуется Node.js 22+.

## Подключение к WhatsApp

1. Создайте приложение на [developers.facebook.com](https://developers.facebook.com/) → тип **Business** → добавьте продукт **WhatsApp**.
2. Подключите номер компании (например, +7 705 615-17-17 или отдельный номер для бота). Номер, уже используемый
   в обычном приложении WhatsApp / WhatsApp Business, нужно сначала удалить из приложения.
3. В **WhatsApp → API Setup** возьмите **Phone number ID** → `WHATSAPP_PHONE_NUMBER_ID` и токен → `WHATSAPP_TOKEN`
   (для продакшена — постоянный токен System User в Business Manager).
4. В **App settings → Basic** скопируйте **App Secret** → `WHATSAPP_APP_SECRET`.
5. Разверните бота на сервере с HTTPS (Railway, Render, VPS + nginx; для локальной проверки — `ngrok http 3000`).
6. В **WhatsApp → Configuration → Webhook** укажите Callback URL `https://ваш-домен/webhook`,
   Verify token = `WHATSAPP_VERIFY_TOKEN`, подпишитесь на поле **messages**.
7. Укажите `MANAGER_PHONE` — номер, куда приходят заявки (формат `77051234567`).
8. Напишите боту «привет».

## Обновление каталога с сайта

Каталог лежит в `data/catalog.json` и импортирован с aimag.kz. Когда на сайте меняются товары или цены:

```bash
npm run import
```

Скрипт читает `sitemap.xml`, открывает страницы товаров и берёт разметку schema.org Product
(название, артикул, бренд, цена, наличие), единицу измерения и параметры. После импорта перезапустите бота.

Условия доставки, оплаты, гарантии для AI-консультанта — в `data/shop-info.md` (собраны со страниц сайта, можно править).

## AI-консультант

Укажите `ANTHROPIC_API_KEY` (ключ с [console.anthropic.com](https://console.anthropic.com/)). Модель — `ANTHROPIC_MODEL`
(по умолчанию `claude-opus-5-5`). Консультант видит информацию о компании и до 15 найденных под вопрос позиций —
весь каталог в каждый запрос не отправляется, поэтому ответы быстрые и недорогие. Если модель отказывается отвечать,
запрос автоматически повторяется на резервной модели. Без ключа бот работает поиском и кнопками.

## Заявки

Заявки и сессии хранятся в `data/db.json`. Список заявок:

```
GET https://ваш-домен/orders?token=<WHATSAPP_VERIFY_TOKEN>
```

## Структура

| Файл | Назначение |
|---|---|
| `src/server.js` | HTTP-сервер, вебхук, проверка подписи, очередь сообщений |
| `src/bot.js` | Диалог: меню, каталог, поиск, заявка на КП |
| `src/catalog.js` | Загрузка каталога и поиск |
| `src/whatsapp.js` | Отправка текста, кнопок и списков через Cloud API |
| `src/ai.js` | AI-консультант на Claude |
| `src/store.js` | Хранилище сессий и заявок |
| `scripts/import-aimag.js` | Импорт каталога с aimag.kz |
| `data/catalog.json` | Товары |
| `data/shop-info.md` | Доставка, оплата, гарантия — для AI |

## Важно

- Свободно отвечать клиенту можно в течение 24 часов после его последнего сообщения; первым писать — только
  одобренными шаблонами. Уведомления менеджеру тоже подчиняются этому правилу: менеджеру нужно хотя бы раз в сутки
  написать боту, иначе уведомления не дойдут.
- На тестовом номере Meta сообщения доходят только до номеров из списка получателей.
